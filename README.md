# Chronik von Kleve

**Status:** Pre-Alpha 0.1

**Version:** `v0.1.0-pre-alpha`

**Baseline:** Sites-Version 32

**Source Commit:** `4906e81d26ac1137e4216cff88eb4de3de9d165e`

Chronik von Kleve is a digital campaign and play platform in development for the private *Vampire: The Masquerade V20* chronicle “Der Hunger bleibt”.

Currently includes:

- Public Shell
- Player area
- Character management
- V20 character sheet
- Character Companion
- Inventory V1
- Carry Profiles
- Body Loadout
- V20-oriented weapon and equipment structure
- Persistent server-side data models

**Pre-Alpha:** This project is under development and is not ready to be treated as a production public platform.
